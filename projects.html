YieldSense AI: Crop Yield Prediction Platform

A full-stack agricultural web app, built as team lead, that predicts crop yield from historical crop data, weather and soil information. An end-to-end ML pipeline (cleaning, feature engineering, training, evaluation) selected Random Forest with about 0.99 R² on the test set. FastAPI + PostgreSQL power JWT auth, farm management, datasets and prediction history, while the React.js interface offers crop recommendations, weather and soil analysis, analytics, and PDF/CSV reports. Deployed on Microsoft Azure with Blob Storage for model management and GitHub Actions CI/CD.

PharmaGuard AI: Pharmaceutical Safety & Recall Platform

An autonomous drug-safety platform that tracks every medicine batch from manufacturer to patient. Each batch gets a keccak256 fingerprint stored in a Solidity smart contract, so any database tampering is detected, and expired, recalled or tampered batches are revoked on-chain and blocked at the pharmacy counter via QR scan. A LangGraph workflow of five AI agents (Recall, Inventory, Compliance, Notification, Summary) runs recalls end to end with deadlines, escalation and Gemini summaries. Includes a NestJS API with role-based access for 6 roles, a React web dashboard, a React Native mobile app with one-tap scan verdicts, real-time and push/SMS notifications, and compliance reports.

NestJS TypeScript React React Native PostgreSQL Prisma Solidity LangGraph Gemini Redis
